# Logotypförslag

Nio riktningar för Skogenskonung. **Ingen av dessa sitter på sajten ännu.**

| Fil | Riktning |
|---|---|
| A-sjospegel | Minimal sjö + granar, kopparspegling |
| B-signatur | Handskriven signatur med tallkvist |
| C-sigill | Cirkulärt sigill, älg i grankrans |
| D-algprofil | Stark älgsiluett, modern |
| E-kronhorn | Horn + krona, skogens konung bokstavligt |
| F-monogram-sk | S och K av horn och gran |
| G-stacked-wordmark | Horn över namnet |
| H-nal-sol | Abstrakt kopparlinje på skogsgrönt |
| I-horisontell-lockup | Gran/horn + SKOGENSKONUNG |
| J-skogens-konung-emblem | Cirkelmärke med älg, EST 1980 — **aktiv på sajten** |
